Stable nonlocal cones and the fractional De Giorgi conjecture in dimension four below one half

October 7, 202657 pagesAI-assisted candidate proof
Read the full PDFView source version →

A candidate proof of one-dimensional symmetry in dimension four for 0 < s < 1/2, built around a classification of stationary stable nonlocal perimeter cones in dimension three.

Candidate proofs. Verification ongoing. Both manuscripts state that verification of all proofs is continuing. This site summarizes the claims in the drafts; it does not establish their correctness.

Four-dimensional statement

Theorem 1.2, on page 2, states that for every 0 < s < 1/2, a bounded entire classical solution of (−Δ)su = u − u³ in ℝ⁴ with ∂₄u > 0 is a planar layer. No assumption is imposed on the limits as x₄ → ±∞.

u(x) = qs(e · x − a)

e ∈ S³, e₄ > 0, a ∈ ℝ

Here qs is the increasing one-dimensional solution, normalized by qs(0) = 0 and qs(t) → ±1 as t → ±∞. The operator uses the Fourier normalization |ξ|2s.

The geometric statement and its hypotheses

Theorem 1.3, on page 2, states that every nontrivial stationary p-perimeter cone in ℝ³ is a halfspace for 0 < p < 1, under the following hypotheses:

  • A locally one-sided smooth boundary away from the origin
  • A compact smooth spherical link
  • Stability under compact variations away from the origin

The parameters satisfy p = 2s. No convexity, symmetry, or link connectedness assumption is imposed. The smoothness and variation hypotheses are part of the statement; it is not a classification of arbitrary singular cones.

Corollary 1.4 states that every bounded stable entire classical solution in ℝ³, for 0 < s < 1/2, is a constant well ±1 or a one-dimensional layer.

Route through the draft

  1. Angular kernels and stability. Sections 2–4 develop kernel identities, a spherical Green identity, and estimates for the spherical link.
  2. Normal-flux pinching. Sections 5–7 treat overlapping perimeter-order ranges. For small p, the argument retains a truncated integral of the exact angular kernel. The estimates are formulated to allow disconnected spherical links.
  3. From cones to the equation. Section 8 connects the geometric classification to the fractional Allen–Cahn equation through stable-solution theory, ordered minimizing-cone splitting, and improvement of flatness.

The appendix records interfaces for formalization and normalization details. The draft presents these arguments as a candidate proof, with verification still in progress.
